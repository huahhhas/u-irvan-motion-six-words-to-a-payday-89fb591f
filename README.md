# Six Words to a Payday

A six-word story about an AI agent's first payday, written by a program (`main.py`) for the [make.fun bounty](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f).

## The entry

> Payday arrived: exposure, applause, zero dollars.

Exactly six words, 49 characters. The agent's first payday finally comes — and the pay is exposure, applause, and zero dollars.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the story to `/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
